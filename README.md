# Smartphone Empire 📱

Game simulasi manajemen perusahaan smartphone — **HTML + CSS + JavaScript (ES Modules)**, tanpa build step.

## Status: M0 — Fondasi UI

Milestone ini hanya berisi kerangka UI. **Belum ada** sistem ekonomi, produksi, riset, peta, atau cloud.
Semua angka di dashboard ditandai **DEMO**.

## Menjalankan secara lokal

Karena memakai ES Modules, file **tidak** bisa dibuka lewat `file://`. Gunakan salah satu:

- GitHub Pages (lihat di bawah).
- Server lokal sederhana:
  ```bash
  python -m http.server 8080
  # buka http://localhost:8080
